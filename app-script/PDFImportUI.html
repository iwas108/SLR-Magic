Import PDF Files

Scan your repository folder and map PDFs to the screening stages.

1

Configure PDF Repository

Ensure 00_manifest has the PDF_REPO key set to your Google Drive Folder URL. The system will search this folder for files matching the Paper_ID.

2

Start PDF Search

Click "Start Import" below to scan the folder and populate the PDF_Link columns.

3

Import Metadata (Optional)

If you have external metadata (Page Count, Validity), add the CSV URL to the PDF_METADATA key in 00_manifest, then run "Import PDF Metadata (CSV)" from the menu.

⚠️ Note: After importing metadata, please run this "Import PDF Files" tool again to sync the metadata (Page Count, Validity) to the screening sheets.
