Import PDF Files

1. Configure PDF Repository
Ensure 00_manifest has the PDF_REPO key set to your Google Drive Folder URL. The system will search this folder for files containing the Paper_ID.
2. Start PDF Search
Click "Start Import" below to populate the PDF column in 03_fulltext_screening.
3. Import Metadata (Optional)
If you have external metadata (e.g., Page Count, Validity), add the CSV URL to the PDF_METADATA key in 00_manifest. Then, run "Import PDF Metadata (CSV)" from the menu.
Note: After importing metadata, please run this "Import PDF Files" tool again to sync the metadata (Page Count, Validity) to the screening sheet.
