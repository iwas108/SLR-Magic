SLR Magic ✨

Workspace for Systematic Literature Reviews, Ingestion, and Visuals

Welcome to SLR Magic Workspace

SLR Magic is a systematic literature review (SLR) workspace designed to help researchers organize, screen, synthesize, and visualize academic literature. The platform automates data ingestion and dynamic visualization, providing a central database for structured literature reviews.

Key System Features

📂 Structured Metadata Ingestion

Bulk ingest literature metadata exports from Scopus/WoS using a fuzzy-matched interactive mapper, or add manual records.

🛡️ Deduplication Guardrails

Automatically screens incoming papers for duplicates by normalising DOIs and Titles to prevent sheet pollution.

📝 Integrated Synthesis Report

Consolidates and maps screened literature directly into 05_Synthesis to construct your final cohort database.

📊 Interactive Visualizations

Generates Sankey diagrams, radar charts, pie charts, stack bar, and line graphs using ECharts directly in Google Sheets dialogs.

💡 Tip: Head to the Configuration menu to fill in your Research Manifesto and metadata before initializing.

The SLR Magic Pipeline

1

Workspace Setup

Run "Initialize Workspace" from the menu to wipe and establish your primary database sheets (00_Raw_Harvest and 05_Synthesis).

2

Metadata Ingestion

Upload your search results CSV (e.g. Scopus or Web of Science) or input manual references via the Ingestion Hub in the Configuration panel.

3

Paper Screening & Synthesis

Review papers in 00_Raw_Harvest, set the "Status" column to "INCLUDE" for chosen literature, then execute "Process Data Collection" to build your Synthesis database.

4

Cohort Visualizations

Launch chart visualizers from the menu to analyze your synthesis data using Sankey, Pie, Bar, Stack Bar, Line, or Radar charts.

About SLR Magic

SLR Magic is a lightweight systematic literature review database tool that integrates metadata ingestion, deduplication checks, manual cohort tagging, and dynamic visual graphics directly inside Google Sheets.

This workspace provides an organized repository for conducting systematic reviews with full compatibility for ECharts-based visualization dashboards.

Core Principles

  • FAIR Data Principles: Promotes findable, accessible, interoperable, and reusable scientific review outputs.
  • Clean Architecture: Strict decoupling of presentation UI, service controllers, and sheet storage managers.
  • Visual Analysis: Native ECharts mapping inside custom modal windows to explore literature attributes.
