SLR Magic ✨

Multi-Persona AI Pipeline for Systematic Literature Reviews

Welcome to Your AI Research Assistant

SLR Magic is a next-generation research automation system designed to eliminate human bias and error in systematic literature reviews. Utilizing a state-of-the-art multi-persona LLM architecture, the platform accelerates screening and extraction tasks while maintaining absolute methodological rigor and auditability.

Key System Features

🤖 Multi-Persona Pipeline

Deploys specialized AI agents sequentially: Fast-Filter, Gatekeeper, Scientist, and Miner.

⚡ Anchored Calibration

Mathematically checks prompt-readiness against a Gold Standard dataset before running the pipeline.

⛏️ Dynamic Schema Extraction

Adapts and generates spreadsheet columns dynamically to parse and map any complex JSON output.

⚖️ Sequential Quality Control

A statistical rolling audit with confidence intervals to verify inter-rater reliability with minimal human labor.

💰 Cost & Token Tracking

Monitors prompt, thinking, input, and output tokens to optimize API expenses.

📊 Rich Visualization

Generates Sankey, Radar, Pie, Bar, Stack Bar, and Line charts directly from review data.

The SLR Magic Pipeline

1

Setup & Initialization

Run "Initialize Workspace" from the menu. The system creates the necessary review sheets with default system-required columns automatically.

2

Metadata Ingestion

Load your search results (e.g., Scopus or Web of Science CSV exports) into the 00_Raw_Harvest sheet using the Ingestion Hub.

3

Pre-Execution Calibration

Export calibration pools to check your LLM prompts against a human-labeled Gold Standard dataset. Iterate until Kappa/F1-score clear thresholds.

4

Phase 1: Abstract Fast-Filter

Execute the Fast Filter screener to quickly exclude irrelevant or out-of-scope papers based on title and abstract logic gates.

5

Phase 2.1: Full-Text Gatekeeper

Filter documents based on full-text methodology. Gatekeeper verifies the physical/cyber-physical context and predictive algorithms.

6

Phase 2.2: Full-Text Scientist

Score the remaining papers against 8 Quality Assessment (QA) criteria. Low quality or failing papers are excluded automatically.

7

Phase 2.3: Data Extraction (Miner)

Run The Miner to extract research parameters and quoted evidence. New columns are appended to the sheet dynamically matching the LLM output keys.

8

Phase 3: Post-Execution QC Audit

Perform rolling micro-batch human reviews of 20 random papers. Auditing stops early as soon as the confidence interval clears predefined targets.

About SLR Magic

The multi-persona LLM framework achieves a statistically significant level of inter-rater reliability comparable to human experts while simultaneously optimizing processing efficiency. This is achieved through a two-tiered, resource-optimized validation architecture consisting of pre-execution calibration and post-execution verification:

1. Pre-Validation Phase

Prior to full-scale pipeline execution, an anchored meta-prompting loop optimizes phase-specific prompts against a human-annotated "Gold Standard" sample dataset. Prompt readiness is mathematically verified using strict target thresholds for F1-score, Cohen's Kappa, and Schema Exactness.

2. Post-Validation Phase (Sequential Quality Control Audit)

Following autonomous processing of the corpus down to the final extracted cohort, the system's generalizability is verified without exhausting human expert resources. Instead of rigid, flat percentage-based sampling, human reviewers execute double-blind assessments on independent, randomized entries in rolling micro-batches of 20 papers. Cumulative performance metrics are re-calculated after each batch alongside their 95% confidence intervals. The human auditing process automatically terminates the moment the lower statistical bound of the confidence interval stably clears predefined performance thresholds (e.g., Kappa ≥ 0.80 for filtering layers, Kappa ≥ 0.65 for complex methodological appraisals).

This end-to-end framework guarantees absolute methodological rigor across the selection funnel while minimizing human verification overhead.

Core Principles
