# SLR Magic: Google Sheets FAIR Compliance Database Blueprint

This document defines the simplified blueprint for the Google Sheets Apps Script environment (`app-script/`). 

In the updated architecture, this module operates strictly as a **FAIR-compliant cloud storage database sink** to preserve finalized literature reference data and metadata. Active processing workflows (e.g. crawler executing, cloud sync, calibration pool assignments, blinded reviews, agreement scoring) have been completely migrated to the local desktop client (`slr-ide`) and the blinded review SPA (`inter-rater`).

---

## 1. Architectural Philosophy

The Sheets Apps Script module is designed to:
1. **Minimize Google Account Permissions**: Eliminates dependencies on expansive OAuth scopes for external scraping or drive access.
2. **Implement FAIR Data Principles**: Ensures the systematic review datasets are *Findable, Accessible, Interoperable, and Reusable* in a shared cloud format.
3. **Serve as a Structured Data Sink**: Records inputs from file-based exports generated by `slr-ide`.

---

## 2. Spreadsheet Database Schema

The spreadsheet initializes and enforces the following standard schema tables to store finalized review cohorts:

### 1. `00_Raw_Harvest`
Archives the total set of raw literature metadata identified during the systematic review search.
* **Headers**: `['Paper_ID', 'Import_Date', 'Import_Source', 'Source', 'DOI', 'Title', 'Abstract', 'Authors', 'Year', 'PDF_Link', 'Status']`

### 2. `05_Synthesis`
Archives references that have passed the screening process (`Status = INCLUDE`) and are ready for data synthesis and qualitative coding.
* **Headers**: `['Paper_ID', 'Import_Date', 'Import_Source', 'Source', 'DOI', 'Title', 'Abstract', 'Authors', 'Year', 'PDF_Link']`

---

## 3. Data Ingestion Protocol

Data is written to this spreadsheet through direct CSV import of file-based exports generated by `slr-ide`:
1. The systematic review team runs search, indexing, PDF matching, and blinded reviews locally on `slr-ide` and `inter-rater`.
2. Upon review completion, the final reference dataset is exported from `slr-ide` as a `.csv` file.
3. The `.csv` is imported or pasted directly into the Google Sheet to synchronize sheets, automatically populating the `00_Raw_Harvest` and `05_Synthesis` sheets.
