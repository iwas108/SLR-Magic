## Overview

The **Inter-Rater SPA** is an offline-capable, standalone React Single-Page Application (SPA) designed to facilitate independent **Blinded Human Reviews** and agreement calibration. It enables reviewers to evaluate assigned paper pools without visibility into other raters' choices or prior AI pipeline decisions, guaranteeing strict scientific rigor and un-biased validation.

Review sessions are synchronized using lightweight, standardized `.slr` (JSON schema) files and persisted locally using `localStorage`.

---

## Key Features

- **Blinded Review Mode:** Evaluates paper abstracts and full texts without displaying AI screening decisions or other human raters' choices.
- **Inter-Rater Calibration Metrics:** Calculates Cohen's Kappa ($\kappa$), overall percentage agreement, and Quality Assessment (QA) score discrepancies.
- **Offline Persistence:** Automatically saves active review state to `localStorage` to guard against data loss or network interruptions.
- **Standardized `.slr` File Exchange:** Imports blinded paper assignments generated by `slr-ide` and exports completed human review files.
- **Responsive Review Interface:** Clean presentation components for single-paper evaluations, decision rationales, QA scoring sliders, and confidence metrics.

## Prerequisites & Setup

### Prerequisites
- **Node.js:** v18.0.0 or higher
- **npm:** v9.0.0 or higher

### Local Development
1. Navigate to the `inter-rater` directory:
   ```bash
   cd inter-rater
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run local development server:
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173` in your browser.

---

## Deployment (GitHub Pages)

The application builds static HTML/JS assets for native hosting on GitHub Pages:

1. Compile production build:
   ```bash
   npm run build
   ```
2. Static assets will be generated in `inter-rater/dist/`.
   *(Note: `vite.config.js` is configured with `base: '/SLR-Magic/inter-rater/dist/'` for GitHub Pages relative asset resolution).*

## Workflow Instructions

1. **Export Assigned Pool (`slr-ide`):**
   In `slr-ide`, navigate to Calibration or Inter-Rater Pool Assignment and export an assigned pool as a `.slr` JSON file.

2. **Conduct Independent Review (`inter-rater`):**
   - Open the Inter-Rater SPA.
   - Import the `.slr` review file.
   - Evaluate each paper independently (Include/Exclude, Rationale, QA criteria scores, Confidence).
   - Export completed `.slr` results file upon finishing.

3. **Adjudicate & Merge (`slr-ide`):**
   Re-import completed `.slr` review files into `slr-ide` for agreement analysis and double-blind calibration adjudication.
